
\section{Conclusion}

What remains from the point of view of the analysis:
\begin{itemize}
\item Discontinuous interpolations (but conforming). Use the techniques in \cite{Codina2009}.
\item Abandon the assumption of quasi-uniform meshes. Use the techniques in \cite{codina2008}.
\item Improved $L^2$ estimates (at least for the primal form) using duality arguments.
\item Convergence.
\item $hp$ analysis.
\item Analyze the formulation that is optimal for equal order interpolations (between the primal and the dual).
\item Consider the prescription of boundary conditions using Nitsche's method, and least for the dual form, where the normal component of vector fields such as $\bm{n}\cdot\sFh$ is not well defined at corners.
\end{itemize}
